# Saveur — бронирование стола

## Как запустить локально

```bash
npm install
npm run dev
```

Приложение: [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## Решения

Состояние формы держит Pinia, правила и сабмит — в composables, страница только переключает экраны. Так проще тестировать логику без DOM и не смешивать валидацию с разметкой. Телефон маскируется при вводе (`+7 (909) 810-12-12`), проверка идёт по 11 цифрам. Время — строго слоты 12:00–22:00, без свободного текста. Подтверждение получает снимок брони пропсами и не читает store, чтобы экран оставался независимым.
